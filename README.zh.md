# @ai-eks/dsh-docking-layout

[English](README.md) | 中文

这是一个 DeepSeek Harness Web UI 插件。Docking Layout 把对话组织成标签，并支持一至四个可拆分的编辑器分组。

```text
┌─ Alpha ─┬─ Beta ─────┬─ 向右拆分 ─┐
│         对话          │             │
│         分组 1        │   分组 2    │
├───────────────────────┼─────────────┤
│         分组 3        │   分组 4    │
└───────────────────────┴─────────────┘
```

插件使用 DSH 原生客户端服务以及公开的 `shell.overlay`、`sidebar.footer.action` 插槽，不需要修改 DeepSeek Harness 源码。每个标签在同源 iframe 中运行指定会话的原生 DSH Web 客户端，完整保留消息记录、输入框、审批、工具展示和会话持久化能力。

## 安装

直接从 Git 安装：

```sh
dsh plugin --profile web add github:ai-eks/dsh-docking-layout
```

安装本地 checkout：

```sh
git clone https://github.com/ai-eks/dsh-docking-layout.git
cd dsh-docking-layout
pnpm install
dsh plugin --profile web add .
```

卸载命令：

```sh
dsh plugin --profile web remove @ai-eks/dsh-docking-layout
```

## 兼容性

插件支持 DeepSeek Harness `0.1.0-rc.8` 和 `0.1.1-rc.2`，使用公开的插槽、会话、工作区、本地化和布局服务，不依赖 `conversation.layout`、多会话 Session provider 或 `ctx.sessions.watch()` 等未发布接口。

插件兼容 `dsh-better-sidebar`：停靠布局覆盖范围会跟随原生对话中心列，外层右侧栏和下边栏继续显示；切换停靠标签不会改变外层 DSH 的当前会话，因此不会反复切换该插件按会话保存的面板状态。iframe 内重复加载的 DSH 侧栏和 `dsh-better-sidebar` 面板会被隐藏。

## 行为

初始分组会把当前对话和一个相邻的可用对话作为标签打开。“打开”菜单按工作区组织剩余对话，并过滤已归档、空白、当前和子 Agent 会话。通过 DSH 侧栏选择普通会话时，插件会在活动分组中打开或聚焦它；即使外层当前会话没有变化，重复点击该侧栏会话也会执行同样操作，并重新打开已关闭的停靠标签。已归档会话和子 Agent 路由会回退到原生对话界面。

把标签拖到另一分组中央会将其移入该组；拖到左、右、上、下边缘会建立相邻分组。工具栏按钮可以把活动标签向右或向下拆分。布局最多保留四个分组；达到上限后，不可执行的边缘拆分会被拒绝，不会被悄悄转换成标签移动。分组中的最后一个标签被移走或关闭后，分组会自动折叠，因此不再提供单独的“关闭分组”操作。

关闭标签只改变浏览器布局，不会删除会话。关闭最后一个标签会在当前停靠布局中创建一个空白对话标签；为空白对话切换工作区时，新对话会替换原标签，不会意外打开其他历史对话。所有 iframe 会保持挂载，因此切换标签后仍保留原生草稿和视图状态；点击 iframe 内容也会把对应分组设为下一次侧栏打开会话的目标。

停靠布局开关固定在 DSH 侧栏底部，同时适配展开和图标栏模式。宽度不超过 760 像素时，分屏会折叠为一个全宽活动分组，并显示带编号的分组切换栏。触屏用户可以切换分组并使用拆分按钮；原生标签拖拽仍主要面向桌面输入。

分屏树、标签分组和启用开关只是当前浏览器的本地偏好。插件不会把会话日志、提示词、审批或文件复制到自己的存储。卸载插件会关闭嵌入的 DSH 客户端并释放其连接，不会修改任何会话。

## 安全与生命周期

插件没有 Host 端运行时，也不创建路由、监听器、进程或网络端口。每个打开的标签创建一个同源 iframe，地址只增加 `dsh-docking-session` 查询参数，不加载第三方页面；iframe 复用当前 DSH 的认证状态，并建立自己的标准 DSH Web 连接。嵌入客户端只会打开由外层停靠布局选择的会话。

插槽注册、本地化文本、偏好 store、iframe 外观和会话列表订阅都由 effect 管理，在插件卸载或 HMR 时自动撤销。

## 模型体验

### Docking Layout

#### 模型可见内容

无。插件只改变浏览器布局，不增加提示词、工具、消息或会话事件。

#### Token 影响

无。每个会话继续使用自己独立的模型请求和消息记录。

#### KV Cache 影响

无。插件不改变模型可见的请求前缀。

## 已知限制

- 全局详情面板和其他插件仍跟随外层 DSH 导航选择，而不是停靠布局中的活动标签。
- 每个打开的标签运行一个 DSH Web 客户端并占用独立连接；同时打开较多标签会增加浏览器内存和连接数。
- 鼠标和触控板可以拖动标签；触屏布局使用拆分按钮和分组切换栏。
- 已归档会话和带地址的子 Agent 路由使用原生对话界面。
- 这是早期独立插件，不承诺稳定性。
